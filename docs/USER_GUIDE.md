# MCP4Intervals 使用指南

## 这是什么？

MCP4Intervals 是一个「骑行 AI 教练」小工具：它读取你在 [Intervals.icu](https://intervals.icu) 里的训练数据，
生成中文骑行日报，通过微信机器人每天定时推送给你；你还能随时在微信里直接问它训练问题，
甚至让它帮你在 Intervals 日历里排好训练课程。

**一句话总结**：把 Intervals.icu 的数据，变成微信里的「每日日报 + 随叫随到的 AI 教练」。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 每日中文日报 | 睡眠 / 静息心率 / HRV / 疲劳 + 昨日活动 + 近 7 天负荷 + 未来 7 天日历 |
| AI 实时问答 | 微信里随时问训练问题，秒回建议 |
| 自动排课程 | 一句话让它把训练写进 Intervals 日历（标题以 AI Coach: 开头）|
| 自选 AI 模型 | DeepSeek / OpenAI / 智谱 / Kimi 等，推荐 DeepSeek（便宜）|
| 多用户隔离 | 每人独立配置，互不干扰 |

## 手把手教程

### 第 0 步：准备两样东西

1. **Intervals.icu 账号**（https://intervals.icu）
   - **运动员 ID**：登录后看地址栏 `intervals.icu/athlete/iXXXXX/…`，其中 `iXXXXX` 就是运动员 ID。
   - **API Key**：进入 Settings（设置）→ 拉到页面底部 → Developer Settings → 生成并复制 API Key。
2. **一个 AI 模型的 API Key**（推荐 DeepSeek，便宜）：到 https://platform.deepseek.com/api_keys 注册并创建 Key。

### 第 1 步：打开系统

浏览器打开管理员给你的地址（例如 `http://<地址>/onboard/`）。

- 第一次用 → 点「去开通 →」进入注册页。
- 已有账号 → 直接输入运动员 ID + 管理密码，点「登录」。

### 第 2 步：注册（首次）

1. **绑定微信**：点「生成二维码」→ 用微信扫码并确认登录 → **给新加的机器人发任意一条消息**（如「开通」）。这步必须做，否则收不到消息。
2. **填 Intervals 凭据**：运动员 ID + API Key（页面上有截图指引，照着找）。
3. **选模型**：模型厂商选 DeepSeek（或别的）→ 自动出现模型名下拉 → 填模型 API Key。
4. **设时间和类型**：时区（默认 Europe/Amsterdam）、每日发送时间、报告类型（AI 分析 / 规则摘要）。
5. **设管理密码**：自己设一个至少 6 位的密码，记住它（以后登录和改设置都要用）。
6. 点「保存」→ 弹出「✅ 开通成功」。

### 第 3 步：收每日日报

每天到你设置的时间，机器人会自动推送一份中文日报到微信。

> 到点没收到？先检查：① 有没有给机器人发过消息（建立会话）；② Intervals API Key 填对没有。

### 第 4 步：微信里问 AI 教练

直接给机器人发消息，例如：

- 「今天能上强度吗？」
- 「我最近疲劳有点高，怎么安排？」
- 「下周怎么练？」

它会读取你最近的训练数据，几秒后回复建议。任何文字都会触发回复。

### 第 5 步：让它帮你排课程

发一句带「安排 / 创建 / 新增」的话，例如：

- 「帮我安排明天一次 1 小时有氧骑」
- 「创建一个周二的间歇训练」

它会回复训练方案，并**自动在 Intervals 日历里创建课程**（标题以 `AI Coach:` 开头）。去 Intervals 就能看到。

### 第 6 步：随时改设置（Dashboard）

登录后进入 Dashboard，可以改：Intervals API Key、时区、发送时间、报告类型、模型厂商 / 模型名 / 模型 Key。改完点保存。

## 常见问题

**Q：收不到日报？**
A：① 先给机器人发一条消息建立会话；② 确认 Intervals API Key 填对；③ 确认微信扫码绑定完成。

**Q：微信问它没反应或报错？**
A：确认「模型 API Key」填对、报告类型选了「AI 分析」。

**Q：模型报 HTTP 错误？**
A：检查 Base URL（选厂商时自动填）、模型名、API Key。

**Q：忘记管理密码？**
A：管理密码是你自己设的，系统只存哈希、不存明文。忘了需要联系管理员删除后重新注册。

**Q：数据 / 隐私安全？**
A：程序只读取你的 Intervals 数据，不修改 FTP / 训练日历（只有你明确要求创建课程时才写），不读聊天记录。凭据都只存在你自己的设备上。
